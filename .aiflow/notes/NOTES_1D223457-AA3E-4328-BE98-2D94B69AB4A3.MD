## Repeat the checks

In a fresh checkout and Python virtual environment, run:

```sh
python -m pip install build twine
python -m build
python -m twine check --strict dist/*
python scripts/check_distributions.py
```

The checker expects exactly one coopy sdist and one wheel. An optional directory
argument selects another artifact directory. It creates and removes fresh
temporary installation environments and persistence data. Installing the sdist
requires access to its build dependencies.

## Enable local checks

From the repository root, in your virtual environment:

```sh
python -m pip install -e ".[dev,test,docs,zstd,lz4]"
pre-commit install
pre-commit run --all-files
python -m pytest -W error::DeprecationWarning --cov=coopy --cov-report=term-missing
python -m sphinx -W --keep-going -E -a -b html docs build/docs
```

Open `build/docs/api.html` for the generated reference. Keep Ruff's version in `pyproject.toml` and `.pre-commit-config.yaml` synchronized when upgrading. See `docs/development.rst` for property-test reproduction and coverage policy.

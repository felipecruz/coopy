# F21: replication security boundary

Password authentication now uses `hmac.compare_digest`, but passwords and replicated data still travel in plain text. Continue using replication only between trusted peers on a trusted network; pickle payloads can execute code when loaded.

Encrypted transport remains future work described in `FUTURE.md` §2.2. If platform-specific polling becomes necessary, use standard-library `selectors` or the proposed pyzmq transport; the empty platform backends have been removed.

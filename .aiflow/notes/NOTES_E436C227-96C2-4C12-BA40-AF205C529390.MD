# F7 checkpoint recovery

F3 already supplied the runtime checkpoint fix. This job adds concurrent-boundary and legacy-compatibility regression coverage and documents the recovery contract. All 89 tests passed on Python 3.12.2/macOS, including 16 checkpoint recovery tests.

## Existing data

Back up the data directory before upgrading. Older journals numbered at or below the latest snapshot remain excluded from replay. If an older writer appended after that snapshot to one of those journals, the files contain no reliable boundary for automatic repair; retain the originals for application-specific recovery.

## Application usage

Take checkpoints through the persistent proxy's `take_snapshot()` or its timer. The low-level `SnapshotManager` alone does not coordinate the domain lock and journal. Keep mutations behind the proxy lock. Pass stable identifiers when referring to existing domain objects: object identity is not guaranteed across independently pickled journal files or between snapshot state and later arguments.

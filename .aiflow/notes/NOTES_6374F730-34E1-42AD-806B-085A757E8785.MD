## Repeat the checks

In a clean checkout with build and twine installed, run:

```sh
python -m build
python -m twine check --strict dist/*
python scripts/check_distributions.py
```

The checker expects exactly one sdist and one wheel in dist/. It creates temporary environments and storage automatically. Isolated builds and sdist installation need access to the package index for build dependencies.

# F10 persistence and recovery guide

The guide and its runnable examples are implemented in commit `9818b8fdb2ff9556fdf7583f512c7b3d0f844b57`. README.md is unchanged.

## Run the checks

From the repository root:

```sh
python -m pip install -e ".[test,docs]"
python -m pytest tests/functional/test_documentation.py
python -m sphinx -W --keep-going -b html docs build/docs
```

Open `build/docs/index.html` for the guide. The replication example requires local socket access. Local validation passed: 118 tests, all four documentation checks after the final example adjustment, and the strict Sphinx build.

## Operating limits

- Use trusted pickle storage and keep a complete backup before upgrades or recovery experiments.
- Stop writers and close the proxy before reopening; close does not take a final snapshot.
- Inspect recovery logs and application invariants. Strict recovery remains F11 work; synchronous durability remains F12 work.
- Replication is experimental and incomplete until F13 is accepted. It does not provide durable slave restart or automatic failover.
